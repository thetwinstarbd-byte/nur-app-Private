# কম্পিউটার ছাড়া APK বানানো (GitHub দিয়ে, বিনামূল্যে)

GitHub-এর সার্ভার আপনার হয়ে APK বানিয়ে দেবে। আপনার কম্পিউটার শক্তিশালী হওয়া লাগবে না, যেকোনো ব্রাউজারই যথেষ্ট।

1. https://github.com এ বিনামূল্যে অ্যাকাউন্ট খুলুন।
2. নতুন একটি repository বানান (নাম: nur-app, Private রাখতে পারেন)।
3. এই ZIP-এর সব ফাইল ও ফোল্ডার (`.github`, `www`, `assets`, `package.json`, `capacitor.config.json`) repository-তে আপলোড করুন। কম্পিউটার থেকে "Add file → Upload files" এ ফোল্ডারসহ টেনে এনে ফেলুন। `.github` ফোল্ডার লুকানো থাকতে পারে, তাই ফাইল ম্যানেজারে "hidden files দেখান" চালু করুন।
4. (ইচ্ছা হলে) আপনার `adhan.wav` ফাইলটি `assets` ফোল্ডারে আপলোড করুন।
5. repository-র **Actions** ট্যাবে গিয়ে **Build APK** বেছে **Run workflow** চাপুন।
6. ৫–১০ মিনিট পর কাজ শেষ হলে সেই run খুলে নিচে **nur-apk** ডাউনলোড করুন। ZIP খুললে `app-debug.apk` পাবেন।
7. ফোনে APK ইনস্টল করুন (সেটিংসে "অজানা উৎস থেকে ইনস্টল" অনুমতি দিতে হবে)।

নোট: এটা পরীক্ষামূলক (debug) APK, নিজের ও পরিচিতদের ফোনে চালানোর জন্য ঠিক আছে। Play Store-এর জন্য আলাদা সই করা ভার্সন লাগবে, সেটা পরের ধাপে করব।
